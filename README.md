# Processing Portfolio

Processingを用いて作成したグラフィック作品のポートフォリオです。

## 作品

### Tully's Coffee Logo
Processingを用いて企業ロゴを再現しました。

使用技術
- Processing
- 図形描画
- 座標制御
- カラー設定

目的
プログラミングによる図形描画の理解を深めること。


2. 星のカービィ – インタラクティブアニメーション
マウス操作に反応するキャラクターアニメーション。ゲーム的な動作ロジックと視覚効果を実装。

実装機能
マウス追従キャラクター描画
敵キャラクターの自動移動と接触判定
三角関数（sin/cos）による星の幾何学描画
画面端反射、ランダム色変化
frameCount によるアニメーション制御
関数分割によるモジュール設計


4. エレベーターシミュレーション
オブジェクト指向設計を用いたエレベーター挙動シミュレーション。複数オブジェクトの状態管理と相互作用を表現。

設計ポイント
Object 基底クラスから People・Elevator を継承
インスタンス間の状態参照による動作制御
ArrayList による複数人物管理
pushMatrix() / translate() による座標管理
状態フラグによる明確な状態遷移設計
