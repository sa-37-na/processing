## 2. 星のカービィ – インタラクティブアニメーション

### 作品概要
Processingを用いて、マウス操作に反応するキャラクターアニメーションを作成しました。  
キャラクターがマウスを追従する動きや、敵キャラクターとの接触判定などを実装し、簡単なゲーム的動作を表現しています。

### 実装機能
- マウス位置に応じたキャラクター追従処理
- 敵キャラクターの自動移動と接触判定
- `sin` / `cos` を用いた星形の幾何学描画
- 画面端での反射処理とランダムな色変化
- `frameCount` を利用したアニメーション制御
- 関数分割によるモジュール化されたコード設計

## 3. エレベーターシミュレーション

### 作品概要
Processingでオブジェクト指向の考え方を用いたエレベーターの挙動シミュレーションを作成しました。  
人やエレベーターをオブジェクトとして扱い、それぞれの状態を管理しながら動作を制御しています。

### 設計ポイント
- `Object` クラスを基底とした `People`・`Elevator` クラスの継承設計
- インスタンス間の状態参照による動作制御
- `ArrayList` を用いた複数人物オブジェクトの管理
- `pushMatrix()` / `translate()` を利用した座標変換
- 状態フラグによる明確な状態遷移の設計
